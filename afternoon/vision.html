Incident Queue

Raw detection / observation ไม่เท่ากับ incident และไม่เท่ากับงานของเจ้าหน้าที่ Dashboard นี้ให้คนตรวจ Incident ที่ระบบรวมแล้ว เพื่อลดการแจ้งซ้ำจากหลาย frame

Priority แบบอธิบายได้: Pending ก่อน แล้วเรียงตามจำนวน observations, peak detected count และความล่าสุด ไม่มี weighted score และยังไม่ได้ calibrate กับพื้นที่บางแสน

Possible Waste Incidents

Flow: Raw Observations → Event Aggregation → Incident → Human Confirm/Reject → ถ้า Confirm = NEEDS CHECK → RESOLVED หลังดำเนินการ

พบครั้งแรก พบล่าสุด กล้อง/จุด สถานที่ พื้นที่ Observations Peak / ล่าสุด Trend Confidence สูงสุด สถานะ การจัดการ
